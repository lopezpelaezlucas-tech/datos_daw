# Práctica RA5 · a+b — Datos e información

## 1) Caso
- Sistema:amazon
- Contexto:Tienda online donde los usuarios compran productos teniendo la 
opcion de dejar una reseña

## 2) Datos
-ID usuario
-Pagina de producto visitada
-Tiempo en la pagina
-Precio del producto
-Cantidad de producto comprada
-Fecha de compra
-Valoracion dada a el producto 
## 3) Información
-Productos mas vendidos a la semana
-Preferencia de consumo
-Analisis de reseñas y valoraciones 
-Horas de mayor trafico en la red

## 4) Diferencia
-Un dato es un valor aislado 
-La informacion es el resultado de estudiar comprender y procesar datos para 
obtener un significado


## 5) Ciclo del dato
- Captura:El usuario navega, selecciona y compra un producto
- Almacenamiento:Los datos se guardan en la base de datos
- Procesamiento:Se organizan y estructuran los datos en la base de datos
- Análisis:Se aplican algoritmos para encontrar patrones de compra, reseñas,
valoraciones, etc ...
- Uso:Se estructura la pagina enn funcion de los productos mas comprados o 
mejor valorados y se recomiendan articulos relacionados con compras 
anteriores de forma personalizada a cada usuario
- Eliminación:Datos antiguos se archivan o eliminan

## 6) Aplicación
- Decisiones:
Que articulo promocionar segun valoraciones y compras
Dar prioridad a ciertos productos a la hora de reponer 
Recomendar productos especificos a usuarios especificos
- Valor:
Tratar y transformar datos nos da la posibilidad de ajustar la pagina de 
forma que sea mas preductiva y rentable 


## 7) Tabla
Dato	                Información
5 estrellas	        Producto altamente valorado
10 compras en 1 hora	Alta demanda del producto
Usuario visita 5 veces	Interés en el producto
Precio 20€	        Producto económico en su categoría
Compra a las 22:00	Hora pico de compras

## 8) Diagrama
Usuario → App → Base de datos → Procesamiento → Análisis → Decisión
## 9) Problemas
Problema 1: Datos incompletos (usuarios no rellenan información)
Solución 1: Validación de formularios y campos obligatorios
Problema 2: Datos erróneos o duplicados
Solución 2: Limpieza de datos y detección de duplicados
